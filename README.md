# skills

Mes skills Claude Code personnels.

## session-handoff

Prépare et exporte le contexte technique de la session en cours dans un fichier
`handoff.md` à la racine du projet, pour reprise par une session B.

Déclencheurs : "fais le handoff", "active le skill de transition", `/session-handoff`.

### Installation

Copier (ou symlinker) le dossier dans `~/.claude/skills/` :

```bash
cp -r session-handoff ~/.claude/skills/
```
